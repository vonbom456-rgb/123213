# Исправленная версия трёх плагинов

## Что исправлено

### PvPCooldowns 1.1

- Контроллер жертвы сохраняется **до** смертельного `TakeDamage`, поэтому
  кулдаун теперь действительно создаётся.
- Дикие динозавры отбрасываются через `BPIsTamed()`.
- Добавлен `MinTribeTeamId` для фильтрации PvE/environmental team id.
- Связь с `TurretControl` восстанавливается после перезагрузки любой DLL.
- При выгрузке указатель callback обнуляется и не остаётся висячим.
- После респавна поддерживается нативный ARK buff HUD со значком и таймером.

### TurretControl 1.3

- Удалено слишком широкое совпадение `riflebullet`: Simple Rifle Ammo больше
  не должно считаться Advanced Rifle Bullets.
- Список игроков для возврата overflow строится заранее.
- Возврат получает ближайший игрок того же племени в радиусе hard-cap scan;
  враг, попавший в обход первым, больше не заставляет удалить патроны владельца.

### DamageAlerts 1.2

- Дикие динозавры явно исключены.
- Учитываются только team id не ниже `MinTribeTeamId`.
- Инициализация/выгрузка перенесены из `DllMain` в штатные экспорты ArkApi
  `Plugin_Init` и `Plugin_Unload`.
- Атакующему отправляются нативные числа урона через проверенный RPC ASE
  `ClientAddFloatingDamageText`: числа рисует сам клиент ARK, поэтому мод не
  требуется. Старое зелёное сообщение чата можно вернуть параметром
  `FloatingDamage.AlsoSendAttackerChat`.

### Проекты сборки

- Из `PvPCooldowns` и `DamageAlerts` удалена нерабочая конфигурация
  `ReleasePermissions`: эти плагины не используют Permissions, а конфигурация
  ссылалась на отсутствующий manifest и могла ломать ручную сборку.

## Как получить значок с мечами и обратный отсчёт

Серверная DLL не может отправить клиенту новую текстуру. Нужен очень маленький
ASE Dev Kit мод:

1. Импортировать `PvPCooldowns/Assets/PvPCooldown_CrossedSwords.png`.
2. Создать дочерний Blueprint от `PrimalBuff` с именем `Buff_PvPCooldown`.
3. Назначить картинку HUD/buff icon.
4. Не добавлять изменение статов, урона, скорости или сопротивления.
5. Оставить отображение buff и timer включённым.
6. Cook/upload мод и установить его на сервер и клиент игроков.
7. Если итоговый путь отличается, прописать его в
   `PvPCooldowns/Plugin/config.json` → `HudBuff.BlueprintPath`.

Ожидаемый путь по умолчанию:

```text
/Game/Mods/PvPCooldowns/Buff_PvPCooldown.Buff_PvPCooldown_C
```

Если мод не установлен или путь неверный, сервер не падает: остаются
периодические сообщения в чат и команда `/pvpcd`.

### Почему PNG нельзя просто встроить в DLL

Этот вариант дополнительно проверен по API ArkApi 3.56. Вызовы HUD принимают
`UTexture2D*` — сетевую ссылку на Unreal-объект, который уже должен находиться
в ресурсах игры клиента. Они не передают содержимое PNG с сервера игроку.
Windows-ресурс `RCDATA` внутри DLL существует только в процессе dedicated
server, поэтому клиент его не загрузит и значок не отобразит.

Без клиентского мода можно использовать только уже имеющийся у всех игроков
vanilla-значок ARK либо текстовое уведомление. В комплект намеренно не добавлен
случайный vanilla buff: у него могут быть скрытые игровые эффекты. Точный
значок с перекрещенными мечами оставлен в `PvPCooldowns/Assets` для безопасного
минимального HUD-мода.

## Сборка

Готовых DLL в архиве нет. Сборка настроена в `.github/workflows/build.yml`:
загрузить содержимое архива в GitHub-репозиторий, открыть Actions, запустить
`Build All Plugins` и скачать artifact `AllPlugins-Release-x64`.

## Обязательная проверка перед боевым сервером

1. Убить игрока другим игроком, прирученным динозавром и турелью другого
   племени: `/pvpcd` должен показывать оставшееся время, `/fill` блокируется.
2. Убить игрока диким динозавром, падением и самоубийством: кулдауна быть не
   должно.
3. После респавна проверить значок и уменьшающийся таймер.
4. Проверить `/fill` с Advanced Rifle Bullets и отдельно с Simple Rifle Ammo.
5. Создать overflow рядом с владельцем и врагом: возврат должен получить
   ближайший онлайн-игрок племени владельца.
6. Проверить DamageAlerts на диком и прирученном динозавре.
7. Проверить перезагрузку `TurretControl`: через один timer tick `/fill` снова
   должен учитывать PvP cooldown.
