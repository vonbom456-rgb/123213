# InventoryCapacity

Standalone ArkApi 3.56 plugin for ARK: Survival Evolved.

- Raises both player inventory slot limits to a configurable safe value.
- Clears ARK's cached full-inventory flag after the limit is raised.
- Fixes `Inventory limit reached` when taking stacks from vanilla or S+ Dedicated Storage while the player still has room under the configured limit.
- Does not modify storage capacity, stack sizes, weight, turrets, or item quantities.

Install the complete `InventoryCapacity` folder under `ArkApi/Plugins` and restart the server.
